# Flashear un ESP32 desde el navegador con ESP Web Tools, sin instalar nada

Código del artículo **[Flashear un ESP32 desde el navegador con ESP Web Tools, sin instalar nada](https://iot.gripe/blog/flashear-esp32-desde-navegador)**, publicado en [iot.gripe](https://iot.gripe).

Cómo agregar a una web app React un botón que detecta si conectas un ESP32-S3 o un ESP32-C3 y le instala el firmware correcto desde Chrome, con ESP Web Tools, el manifiesto y el borrado de la flash.
