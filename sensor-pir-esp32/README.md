# Sensor de movimiento PIR con ESP32: encender una luz al detectar presencia

Proyecto paso a paso con un sensor PIR HC-SR501 y un ESP32: conexión, ajustes de sensibilidad y tiempo, código para encender una luz con temporizador y cómo evitar falsas detecciones.
